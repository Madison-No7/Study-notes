# 一、获取当前正在执行的方法名
## 1.`sys._getframe()`（性能最好、最轻量）
```
import sys

class Example:
    def my_method(self):
        # f_code.co_name 即为当前代码对象的名称
        current_func_name = sys._getframe().f_code.co_name
        print(f"当前方法名: {current_func_name}")

Example().my_method()
# 输出: 当前方法名: my_method
```
# 二、获取【调用当前函数的上一层函数（调用者）】的名称的方法名
## 1.sys.getframe(1).f_code.co_name
```
import sys

def target_method():
    # 参数 1 代表上一层调用栈
    caller_name = sys._getframe(1).f_code.co_name
	    #与caller = sys._getframe().f_back.f_code.co_name等价
    print(f"我被谁调用了: {caller_name}")

def main_process():
    target_method()

main_process()
# 输出: 我被谁调用了: main_process
```

| **代码片段**          | **含义与作用**                                        |
| ----------------- | ------------------------------------------------ |
| `sys._getframe()` | 获取**当前正在执行**的作用域的栈帧对象（Frame Object，深度为 0）。       |
| `.f_back`         | 获取当前栈帧的**前一个栈帧**（即调用方 / 上一层函数）。                  |
| `.f_code`         | 访问该栈帧对应的**代码对象**（Code Object），里面存放了字节码、变量名表等元数据。 |
| `.co_name`        | 读取该代码对象的**名称字符串**（即函数名、方法名或 `<module>`）。         |
