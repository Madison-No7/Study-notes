
# 一、匹配单个字符串
| 正则规则       | 说明                     | 示例代码                                                         | 匹配结果  |
| ---------- | ---------------------- | ------------------------------------------------------------ | ----- |
| `.`        | 匹配任意一个字符，除了换行符 `\n`    | `python res=re.match('.','hello') print(res.group())`        | `h`   |
| `[字符集合]`   | 匹配括号中任意一个字符            | `python res=re.match('[he]','hello') print(res.group())`     | `h`   |
| `[0-9]`    | 匹配0~9之间任意一个数字          | `python res=re.match('[0-9]','54321') print(res.group())`    | `5`   |
| `[a-z]`    | 匹配小写字母                 | `python res=re.match('[a-z]','hello') print(res.group())`    | `h`   |
| `[A-Z]`    | 匹配大写字母                 | `python res=re.match('[A-Z]','Hello') print(res.group())`    | `H`   |
| `[a-zA-Z]` | 匹配任意大小写字母              | `python res=re.match('[a-zA-Z]','hello') print(res.group())` | `h`   |
| `\d`       | 匹配一个数字，相当于 `[0-9]`     | `python res=re.match('\d','4565') print(res.group())`        | `4`   |
| `\D`       | 匹配一个**非**数字字符          | `python res=re.match('\D','l565') print(res.group())`        | `l`   |
| `\s`       | 匹配空白字符，包括空格、tab、换行     | `python res=re.match('\s..',' l565') print(res.group())`     | `l`   |
| `\S`       | 匹配**非**空白字符            | `python res=re.match('\S..',']l565') print(res.group())`     | `]l5` |
| `\w`       | 匹配单词字符，包括：字母、数字、下划线、汉字 | `python res=re.match('\w','呵呵') print(res.group())`          | `呵`   |
| `\W`       | 匹配**非**单词字符            | `python res=re.match('\W','.hehe') print(res.group())`       | `.`   |
# 二、匹配多个字符
这些符号都是**作用于前面的一个字符或者表达式**。

| 正则规则    | 说明                     | 示例代码                                                              | 匹配结果    |
| ------- | ---------------------- | ----------------------------------------------------------------- | ------- |
| `*`     | 匹配前一个字符出现0次或无限次，可以没有   | `python res=re.match('\w*','hello 123') print(res.group())`       | `hello` |
| `+`     | 匹配前一个字符出现1次或无限次，至少出现一次 | `python res=re.match('\d+','11hello 123') print(res.group())`     | `11`    |
| `?`     | 匹配前一个字符出现0次或1次         | `python res=re.match('\d?','11hello 123') print(res.group())`     | `1`     |
| `{m}`   | 匹配前一个字符出现m次            | `python res=re.match('\d{2}','116hello 123') print(res.group())`  | `11`    |
| `{m,n}` | 匹配前一个字符出现m到n次          | `python res=re.match('\d{1,7}','11hello 123') print(res.group())` | `11`    |
# 三、匹配开头和结尾
## 1. `^` 匹配字符串开头
| 规则  | 说明        | 代码                                                          | 结果   |
| --- | --------- | ----------------------------------------------------------- | ---- |
| `^` | 匹配字符串开始位置 | `python res=re.match('^he','hello 123') print(res.group())` | `he` |
注意：`^`在 [ ] 里面表示取反
```python
res=re.match('[^1]','hello 123')
print(res.group())
```
含义：匹配不是1的字符
结果：h

## 2. `$` 匹配字符串结尾

|规则|说明|代码|结果|
|---|---|---|---|
|`$`|限定匹配必须出现在字符串末尾|`python res=re.match('.{8}\w$','hello 123') print(res.group())`|`hello 123`|
**例如：** abc$    表示：必须以abc结尾

# 四、匹配分组

| 编号  | 正则规则 | 功能说明          | 代码示例                                                                            | 匹配结果             |
| --- | ---- | ------------- | ------------------------------------------------------------------------------- | ---------------- |
| 1   | \|   | 匹配左右两个表达式任意一个 | abc\|def                                                                        | 匹配 abc 或者 匹配 def |
| 2   | `()` | 将括号中的内容作为一个分组 | res=re.match( '\w*@(163\|qq\|gmail126).com', '123@163.com' ) print(res.group()) | 123@163.com      |

# 六、命名分组
| 编号  | 正则规则         | 功能说明     | 代码示例          | 匹配结果     |
| --- | ------------ | -------- | ------------- | -------- |
| 1   | `(?P<name>)` | 给分组设置别名  | `(?P<L1>\w*)` | L1代表该分组  |
| 2   | `(?P=name)`  | 通过名字引用分组 | `(?P=L2)`     | 引用L2匹配内容 |
代码：
```python
res=re.match(
'<(?P<L1>\w*)><(?P<L2>\w*)>.*</(?P=L2)></(?P=L1)>',
'<html><body>login</body></html>'
)

print(res.group())
```
